如何将暗投改为明投

按f12将PAGE G B版暗投 下方一行完全展开（点向右的三角形）后在<style>找到以下文字（应该在前半段）

  /* 投票输入框（完全隐藏输入文字，保留占位符） */
        .vote-input {
            padding: 10px;
            font-size: 1.1em;
            width: 100%;
            box-sizing: border-box;
            border: 2px solid #ddd;
            border-radius: 4px;
            margin-bottom: 10px;
            color: transparent;
            text-shadow: none;
            caret-color: transparent;
        }
        .vote-input:focus {
            border-color: #007BFF;
            outline: none;
        }
将color: transparent;改为color:black;
